3. Plus court chemin (shortest_path)
====================================
shortest_path("A", "G") -> A → C → B → D → E → F → G (coût 14)
shortest_path("A", "H") -> aucun chemin   [H est isolé]
shortest_path("G", "A") -> aucun chemin   [sens inverse]
shortest_path("A", "A") -> A (coût 0)   [départ = arrivée]

4. Sommet interdit (shortest_path_avoiding)
===========================================
shortest_path_avoiding("A", "G", "C") -> A → B → D → E → F → G (coût 15)
shortest_path_avoiding("A", "G", "D") -> A → C → E → F → G (coût 16)
shortest_path_avoiding("A", "G", "F") -> A → C → B → G (coût 18)
shortest_path_avoiding("A", "G", "G") -> aucun chemin   [interdit = arrivée : impossible]
